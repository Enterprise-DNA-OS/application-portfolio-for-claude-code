# Why this base has no front end

The application review is a small set of recurring jobs: assign owners, check support and renewal dates, validate dependencies, record decisions and review evidence. These jobs work from a database and the coding agent already used by the operator.

The base produces read-only HTML snapshots and printable documents. They are local review artefacts, not a hosted application or a Command Centre. Actions run through the CLI and its recipes. An installed Command Centre view is a separately scoped service.

Ardoq also provides diagrams, collaborative modelling, surveys, integration options and configurable reporting. Those are real capabilities. This base is a bounded application portfolio system, not a feature-for-feature replacement for every architecture workspace.

It does not provide mobile data entry, offline synchronisation, drag-and-drop diagrams, a visual scenario editor, live infrastructure discovery or automatic identity management. Enterprise DNA can scope the connections and business views your version needs. A customer Command Centre's views belong in its existing shell.

The software licence has no seat or application limit. Hosting, coding-agent usage, access management and support still have costs. Shared Postgres operation needs authenticated users, database permissions and tested backups. Local PGlite operation runs one process at a time.
